# Security Policy

## Reporting a Vulnerability

Do not open a public issue for a vulnerability. Report it privately through GitHub private vulnerability reporting:

https://github.com/nekonaru/lumenfetch/security/advisories/new

Include what you found, how to reproduce it, and the impact you expect. You will get an initial response as soon as possible.

## Scope

This policy covers the code in this repository (the `lumenfetch` CLI). Issues in `yt-dlp` itself belong upstream: https://github.com/yt-dlp/yt-dlp/issues

## What to Expect

- Reports are read by the maintainer and investigated in priority order.
- If a report is accepted, a fix is prepared privately, then released before any public details are shared.
- If a report is rejected, you will get a short explanation.

## Supported Versions

Only the latest release on PyPI and the latest release on GitHub get security fixes.
