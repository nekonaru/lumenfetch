# Versions are intentionally NOT pinned (e.g. "yt-dlp==2026.1.1"): YouTube
# changes its systems often, and yt-dlp needs regular updates to stay
# compatible (see core/update_checker.py). Run "pip install --upgrade yt-dlp"
# periodically.
#
# Core dependencies (required): yt-dlp, rich, curl_cffi.
# - curl_cffi: TLS impersonation (required to pass YouTube's bot checks)
# Everything else is optional - the app runs without them (degrades gracefully):
# - pyperclip: clipboard auto-paste (without it, paste manually)
# - static-ffmpeg: bundled ffmpeg (without it, a system ffmpeg is needed to
#   merge MP4 & extract MP3)

rich
curl_cffi
